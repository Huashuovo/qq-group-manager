# koishi-plugin-qq-group-manager

[![npm](https://img.shields.io/npm/v/koishi-plugin-qq-group-manager?style=flat-square)](https://www.npmjs.com/package/koishi-plugin-qq-group-manager)

一个面向 QQ 群的 Koishi 群管插件，提供**入群自动审核**、**退群记录**、**黑名单管理**和**退群广播**功能。
入群申请老是有管理员**忘记看等级**，那些本不该能进群的人也**改个id就认不出来了**，索性写个插件自动化吧

## 功能

### 入群自动审核

收到入群申请时，按以下顺序依次检查，命中任一条件即自动拒绝：

1. **黑名单检查**：申请人在本群黑名单中，自动拒绝。
2. **QQ 等级检查**：申请人 QQ 等级低于设定值，自动拒绝。等级获取失败或未公开时跳过此检查。

若是未命中，则**检查关键词**，若命中关键词则自动放行，未命中管理员自行审核

### 退群记录

监听成员退群事件，记录每次退群的**时间**和**类型**：

- `leave`：主动退群
- `kick`：被管理员踢出
- `unknown`：无法判断类型

### 退群广播

当有人申请入群时，如果该用户在本群有 **2 次及以上**退群记录，自动向指定群发送提醒。

### 黑名单管理

支持按群增删查黑名单，每条记录包含：

- QQ 号
- 拉黑原因
- 备注（光看QQ号应该看不出这是谁吧）
- 拉黑时间

## 命令

所有命令仅对 `allowedUserIds` 中的用户生效，其他用户静默无响应，且只能在群聊中使用。
